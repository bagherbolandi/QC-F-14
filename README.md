# QC-F-14 — بازطراحیِ سامانۀ ثبتِ قطعاتِ برگشتی / ضایعات / اصلاحی

این مخزن دو چیز دارد: **فایلِ بازسازیشده** و **ابزارهایی که آن فایل را می‌سازند و می‌سنجند**.
هیچ بخشیِ فایل «دستی» ویرایش نشده؛ هر چیزی که در `QC-F-14-v2.xlsx` می‌بینید، خروجیِ
`tools/` است — پس قابلِ بازتولید و قابلِ بازبینی‌است.

## فایل‌ها

| مسیر | چیست |
|---|---|
| `QC-F-14-v2.xlsx` | **تحویلِ فاز ۲–۹** — ۱۲ شیت، `tblQC` با ۲۶ ستون و ۱۴٬۵۵۷ رکوردِ مهاجرت‌یافته، ۱۵ گزارش، داشبورد، DQ، راهنما. ماکرو-آزاد (ماکرو جداست، پایین ببینید) |
| `FORM-QC-F-14.xlsm` | فایلِ **مرجع** (قبلِ بازطراحی). فقط‌خواندنی؛ هیچ ابزاری روی آن نمی‌نویسد |
| `vba/QC_WritePath.bas` | تنها ماژولِ VBA: مسیرِ نوشتن (`QC_Append`، `QC_Import_Staging`، `QC_VoidRow`، `QC_ClearForm`، `QC_About`) + `vba/README-vba.md` برای نصبِ ۲ دقیقه‌ای |
| `analysis/00…04-*.md` | گزارش‌ها: ۰۰ چک‌لیستِ فاز ۱ · ۰۱ نیازمندی‌هایِ تأییدشده · ۰۲ یافته‌هایِ تحلیل · ۰۳ گزارشِ طراحی (بخش A–J) · **۰۴ گزارشِ ساخت، آزمون‌ها، و تحویل** |
| `tools/` | `build_payload.py` (مغز: مهاجرت + قواعد) · `gen_workbook.py` (سازندهٔ فایل) · `xlcal.py` (تقویمِ جلالی) · `xlmigrate.py` (پارس/نرمال‌ساز) · `msovba.py` (کدکِ MS-OVBA) · سه آزمون + `make_vba.py` |
| `analysis/reverse_engineer.py` | حسابرسِ فایل (ساختارِ XML، فرمول‌ها، DV، لاگِ VBA) + `migration_check` برای اثباتِ «مهاجرت چیزی را نمی‌خورد» |

## ساختنِ دوباره و آزمون‌ها

```bash
python3 -W ignore tools/build_payload.py FORM-QC-F-14.xlsm -o analysis/payload.json
python3 -W ignore tools/gen_workbook.py --payload analysis/payload.json -o QC-F-14-v2.xlsx
python3 -W ignore tools/test_workbook.py QC-F-14-v2.xlsx        # T-W0…T-W12
python3 -W ignore tools/test_jalali.py                           # T-J1…T-J6
python3 -W ignore tools/make_vba.py vba/QC_WritePath.bas --workbook QC-F-14-v2.xlsx
```

آخرین وضعیتِ اجرا: **همه سبز** — ۱۴٬۵۵۷/۱۴٬۵۵۷ رکورد، صفرِ اختلافِ بارکد
(۱۴٬۰۷۹ متمایز، ۹٬۲۸۳ بارکد با صفرِ ابتدایی حفظ‌شده)، `ضایعات/اصلاحی/برگشتی =
۱٬۶۴۵/۱۲٬۸۱۴/۹۸`، و `migration_check: FAILS: NONE`. جزئیاتِ عددی و چک‌لیستِ پذیرشِ دستی در
Excel داخلِ `analysis/04-build-and-handoff.md` است (§۳ و §۵).

## سه هشداری که در خودِ فایل هم نوشته شده

1. **همزمانیِ چند کاربر روی یک فایلِ مشترک پشتیبانی‌نشده است** — الگو: یک فایل به‌ازای
   ایستگاه + تجمیعِ مرکزی.
2. Excel دیتابیس/سیستمِ امنیتی نیست؛ `LOG_AUDIT` best-effort است و «ممیزیِ قانونی» ادعا نمی‌شود.
3. دو شاخص («نرخِ ضایعات بر تولید»، «تأخیرِ ثبت») به‌دلیلِ **نبودِ داده** ساخته نشدند؛ در
   شیت Settings با ❌ علامت خورده‌اند تا کسی عددِ ساختگی را نبیند.
