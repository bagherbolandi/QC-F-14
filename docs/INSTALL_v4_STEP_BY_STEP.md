# راهنمای کامل نصب و اجرای QC-F-14 v4 — برای کسی که تا حالا ماکرو نصب نکرده

> این راهنما را از بالا تا پایین، بدون رد کردن هیچ مرحله، انجام دهید. ۵ دقیقه طول می‌کشد.

## ۰. پیش‌نیازها

- **Excel Desktop** روی ویندوز (نسخه 2016، 2019، 2021 یا 365). **Excel Online / مرورگر / موبایل ماکرو ندارد و لاگین کار نمی‌کند.**
- فایل‌های زیر را از ریپو دانلود کنید (یا از همین Workspace):
  - `QC-F-14-v4.xlsx` (یا `QC-F-14-v4-READY-TO-LOGIN.xlsx` که نام کاربری از قبل پر است)
  - `vba/QC_Full_v4.bas`
  - `vba/ThisWorkbook_v4.bas`
- همه را در **یک پوشه** بریزید، مثلاً `C:\QC\`

## ۱. فعال کردن تب Developer (فقط یک‌بار)

1. اکسل را باز کنید → `File → Options → Customize Ribbon`
2. سمت راست، تیک `Developer` را بزنید → OK
3. حالا در نوار بالا تب `Developer` می‌بینید.

## ۲. پوشه را Trusted کنید (تا اکسل ماکرو را بلاک نکند)

1. `File → Options → Trust Center → Trust Center Settings → Trusted Locations`
2. `Add new location → Browse → پوشه C:\QC را انتخاب → تیک Subfolders → OK → OK → OK`
3. اکسل را ببندید.

## ۳. فایل را به xlsm تبدیل کنید

1. روی `QC-F-14-v4.xlsx` دابل‌کلیک کنید → باز می‌شود، فقط شیت `LOGIN ورود` دیده می‌شود (این طبیعی است، بقیه VeryHidden هستند)
2. `File → Save As → Browse → نوع فایل را انتخاب کنید: Excel Macro-Enabled Workbook (*.xlsm)`
3. نام بگذارید `QC-F-14-v4.xlsm` → Save
4. **از این به بعد فقط با همین xlsm کار کنید**، xlsx را کنار بگذارید.

## ۴. ماکرو را Import کنید (مهم‌ترین مرحله)

1. در همین فایل `QC-F-14-v4.xlsm` که باز است، کلید `Alt + F11` را بزنید → پنجره سیاه VBA باز می‌شود
2. در منوی بالا: `File → Import File...`
3. بروید به پوشه `C:\QC` → فایل `QC_Full_v4.bas` را انتخاب → Open
4. سمت چپ، می‌بینید یک ماژول به نام `QC_Full_v4` اضافه شد.
5. حالا در سمت چپ، روی `ThisWorkbook` دابل‌کلیک کنید → سمت راست یک صفحه سفید باز می‌شود
6. فایل `ThisWorkbook_v4.bas` را با Notepad باز کنید → همه متن آن را `Ctrl+A, Ctrl+C` کپی کنید → در صفحه سفید VBA `Ctrl+V` کنید
7. `Ctrl+S` بزنید → پنجره VBA را ببندید (`Alt+Q` یا X)

## ۵. دو دکمه ورود و خروج بسازید

1. برگردید به اکسل، شیت `LOGIN ورود`
2. تب `Developer → Insert → Button (Form Control)` → اولین آیکون (مستطیل) را انتخاب
3. کنار سلول `C6` (نام کاربری) یک مستطیل بکشید → پنجره Assign Macro باز می‌شود → `QC_Login` را انتخاب → OK
4. روی دکمه راست‌کلیک → `Edit Text` → بنویسید `ورود` → Enter
5. دوباره `Developer → Insert → Button` → کنار `C8` (رمز عبور) یک دکمه دیگر بکشید → `QC_Logout` → متن `خروج`

> اگر Assign Macro را اشتباه زدید: روی دکمه راست‌کلیک → Assign Macro → درست را انتخاب کنید.

## ۶. اولین ورود

1. در `C6` بنویسید `admin` (اگر از فایل READY-TO-LOGIN استفاده می‌کنید از قبل پر است)
2. در `C8` بنویسید `admin123`
3. دکمه `ورود` را کلیک کنید → باید پیغام `ورود موفق — دسترسی ادمین (همه شیت‌ها)` بیاید → OK
4. حالا همه شیت‌ها دیده می‌شوند: Data, FORM, Dashboard, Reports, Master, USERS, LOG_AUDIT...

## ۷. تست نقش‌ها

- دکمه `خروج` → دوباره فقط LOGIN می‌ماند (امن)
- `operator / 1234` → ورود → فقط FORM + STAGING + Help
- `viewer / viewer123` → Dashboard + Reports + DQ + Help
- `i-01 / 1234` → مثل operator (بازرس)

## ۸. اگر لاگین کار نکرد — چک‌لیست عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| فقط LOGIN دیده می‌شود و دکمه ورود هیچ کاری نمی‌کند | ماکرو Import نشده: Alt+F11 → آیا ماژول QC_Full_v4 هست؟ اگر نیست مرحله ۴ را تکرار |
| پیغام Security Warning زرد بالا | روی `Enable Content` کلیک کنید، یا مرحله ۲ (Trusted Location) را انجام دهید |
| دکمه‌ها کلیک نمی‌شوند | روی دکمه راست‌کلیک کردید؟ باید چپ‌کلیک کنید. اگر در حالت Design هستید: Developer → Design Mode را خاموش کنید |
| ارور `E_LOGIN` | نام کاربری/رمز را انگلیسی تایپ کنید، Caps Lock خاموش، فاصله اضافی ندهید |
| فایل `xlsm` باز نمی‌شود و ارور فرمت می‌دهد | شما فایل xlsx را فقط Rename کردید به xlsm. باید از داخل اکسل Save As کنید به نوع xlsm (مرحله ۳) |
| Excel Online باز کردم | با Desktop باز کنید، Online ماکرو ندارد |

## ۹. بعد از نصب، چه کنید؟

- فایل `QC-F-14-v4.xlsm` را همیشه از همین پوشه Trusted باز کنید
- برای ثبت: با `operator` وارد شوید → FORM → 11 فیلد را پر → دکمه `QC_Append` (باید برای FORM هم یک دکمه بسازید و Assign به QC_Append)
- برای گزارش: با `viewer` یا `admin` وارد شوید → Dashboard / Reports
- برای خروج امن: همیشه دکمه `خروج` را بزنید قبل از بستن فایل → فایل با فقط LOGIN ذخیره می‌شود

## ۱۰. فایل‌های تحویل

- `QC-F-14-v4.xlsx` → فایل اصلی سالم (بدون ماکرو، فقط LOGIN Visible)
- `QC-F-14-v4-READY-TO-LOGIN.xlsx` → همین ولی C6/C8 از قبل admin/admin123 پر است
- `QC-F-14-v4-FULL-VISIBLE.xlsx` → همه شیت‌ها Visible برای حسابرسی (بدون نیاز به ماکرو)
- `vba/QC_Full_v4.bas` + `ThisWorkbook_v4.bas` → کد ماکرو

> **نکته امنیتی:** رمزها Plain Text در شیت USERS هستند. این برای Excel طبیعی است. برای امنیت واقعی باید به SQL/Web مهاجرت کنید. این لاگین فقط برای جلوگیری از دسترسی اتفاقی اپراتور است.

اگر باز هم اجرا نشد، اسکرین‌شات از خطا + نام فایلی که باز کردید بفرستید.
