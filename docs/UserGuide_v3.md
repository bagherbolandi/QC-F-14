# User Guide — QC-F-14 v3

## نصب

1. فایل `QC-F-14-v3.xlsx` را باز کنید (Excel Desktop 365/2021)
2. برای فعال‌سازی ماکرو: Alt+F11 → File → Import File → `vba/QC_WritePath_v3.bas` → Save As `.xlsm`
3. در FORM، یک Shape بکشید → Assign Macro → `QC_Append`
4. پوشه را Trusted Location کنید (File → Options → Trust Center)

## ثبت روزانه

1. FORM فرم ثبت:
   - تاریخ وقوع (شمسی)* — از لیست 180 روز اخیر
   - شیفت* — S1/S2/S3
   - ایستگاه* — فقط فعال‌ها (کنترل نهایی, برگشت از فروش)
   - بازرس* — از لیست
   - قطعه* — کد | نام
   - قالب* — A-E یا راست/چپ
   - بارکد* — اسکن 19 رقمی (صفر ابتدایی حفظ می‌شود)
   - نتیجه بازرسی* — OK (بدون عیب) یا NOK (دارای عیب)
   - عیب — اگر NOK الزامی
   - تعیین تکلیف* — ACCEPT, REWORK, SCRAP, RETURN_TO_PROCESS, HOLD
   - وضعیت فعلی — اگر خالی، خودکار: REWORK→UNDER_REWORK, HOLD→OPEN, بقیه CLOSED
   - توضیح — اختیاری
2. پیام C28 باید "✓ آماده ثبت" باشد
3. دکمه ثبت → RECORD_ID مثل QC-00000001 ساخته می‌شود، پیام "✓ ثبت شد"
4. اگر بارکد تکراری: نوع رکورد خودکار REINSPECTION + وضعیت OPEN + پیام "مشکوک-تکراری" (رد نمی‌شود)

## Barcode History

- Reports → R11: بارکد را در D وارد کنید
- تعداد رکورد، و تا 10 ردیف تاریخچه با Record_ID, تاریخ, نوع, شیفت, ایستگاه, قطعه, عیب, نتیجه, تعیین تکلیف, وضعیت, بازرس

## STAGING (بدون VBA)

- اگر ماکرو بلاک شد: STAGING ورود اضطراری
- B..K را پر کنید (تاریخ, شیفت, ایستگاه, بازرس, قطعه, قالب, بارکد, نتیجه, عیب, تعیین تکلیف, وضعیت)
- ستون L FLAG باید "✓ آماده Import" باشد
- سپس ماکرو QC_Import_Staging (یا دکمه) → به tblQC اضافه و ردیف STAGING پاک می‌شود

## Void (ابطال)

- در Data داده، یک سلول از ردیف موردنظر را انتخاب کنید → QC_VoidRow
- دلیل الزامی (RULE-07)
- رکورد حذف نمی‌شود: CURRENT_STATUS=VOID, VOID_FLAG=TRUE, ROW_STATUS=ابطال‌شده

## گزارش‌ها

- 15 گزارش در Reports: روند روزانه/ماهانه/هفتگی, شیفت×نوع, ایستگاه×نوع, 15 قطعه برتر, Pareto عیب, قالب×نوع, بازرس, Disposition, Barcode History, ماتریس قطعه×عیب, تکراری/عقب‌گرد, کیفیت داده, خلاصه مدیریتی
- فیلترها در Dashboard G4:G16: سال, ماه, روز, هفته, شیفت, ایستگاه, قطعه, قالب, عیب, نوع رکورد, تعیین تکلیف, وضعیت فعلی, نتیجه بازرسی — "همه" = بدون فیلتر

## Dashboard

- K1 کل رکوردها (14,557 مهاجرت), K2 بارکد یکتا (14,079), K3 NOK, K4 OK, K5 Rework, K6 Scrap, K7 Return, K8 نرخ ضایعات
- تفاوت Record Count vs Unique Barcode حفظ شده
- نمودار روند ماهانه Disposition

## DQ کیفیت داده

- 6 قانون: بارکد ≠19, تکراری, NOK بدون عیب, OK با عیب, VOID بدون دلیل, OPEN قدیمی
- شمارش با فرمول زنده, 200 ایراد ردیفی اول از مهاجرت

## Master Data

- فقط در Master اطلاعات پایه، داخل Table
- افزودن: ردیف جدید در Table, CODE یکتا, ACTIVE=بله
- غیرفعال: ACTIVE=خیر (از فرم حذف, تاریخچه می‌ماند)
- 6 ایستگاه بلااستفاده: ENABLED_FOR_FORM=خیر

## محدودیت‌ها

- یک فایل به‌ازای ایستگاه — چندکاربره همزمان روی یک فایل = از دست رفتن داده
- Excel دیتابیس نیست — تراکنش ندارد
- LOG_AUDIT best-effort
- سقف عملیاتی ~25k ردیف/سال
- تقویم شمسی متنی, بدون وابستگی به ویندوز
